Wisp Forest

Awaken the forest

Collect wisps, manage energy, survive spirit patrols, then break the shrine sentinel in a final arena.

Controls

  • A / D or Left / Right: move
  • Space: jump and double jump
  • Shift / K: dash
  • J / Z: spirit bolt
  • W / Up + J: shoot up, W / Up + A/D + J: shoot diagonal
  • P / Esc: pause
  • R: restart run

Goal

Restore the forest shrine, cross into the desert ruins, then clear a second sanctum to finish the run.

Design

The build now runs across two biomes with directional spirit shots, expanded traversal space, and a desert stage that still follows the project global style.
