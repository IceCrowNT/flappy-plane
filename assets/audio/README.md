Drop your background music file here using one of these names:

- `sky-journey.ogg`
- `sky-journey.mp3`
- `sky-journey.wav`

The game will automatically use that file as looping BGM.

If no file is present, the game falls back to a lightweight built-in synth melody so audio still works.

Recommended music direction:

- warm orchestral or acoustic
- whimsical flying mood
- soft intro and clean loop
- around 60-90 seconds
