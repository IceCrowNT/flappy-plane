# Flappy Plane Repo Map

## Product Shape

- Root page is an arcade dashboard at `index.html`.
- Live game routes:
  - `/games/flappy-plane/`
  - `/games/wisp-forest/`
- Tech stack is plain HTML, CSS, and browser JS modules with a tiny Node static server.

## Existing Visual Language

- The repo already leans arcade, playful, and hand-crafted instead of enterprise UI.
- Fonts currently use Google Fonts and pixel / decorative type.
- Main surfaces use layered gradients, illustrated scenery, rounded frames, and game-like badges.

## Structural Constraints

- Keep each game self-contained under its own route folder.
- Avoid introducing a framework unless the user explicitly asks for one.
- Preserve lightweight loading and static-host friendliness.

## Good Stitch Directions For This Repo

- Cozy arcade cabinet
- Storybook sky adventure
- Hand-painted indie game launcher
- Festival poster meets game dashboard

## Bad Stitch Directions For This Repo

- Generic B2B dashboard
- Crypto / fintech gradients
- Minimal monochrome portfolio
- Dense admin table layouts

## Expected Output Quality

- Strong hero section with a clear CTA into a game
- Card system for current and upcoming games
- Visual distinction between live games and ideas
- Mobile-friendly layout that still feels like a game hub
